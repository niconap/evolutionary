- n=5 per condition, standard deviations are large relative to the

- No statistical significance test has been performed or is claimed.
- This is a single noisy stochastic-simulation EA; conclusions should be
  treated as a trend/hypothesis, not a confirmed effect, pending more seeds
  or a formal test.

================================================================
5. KNOWN CAVEATS FOR THE EVALUATING AGENT
================================================================
- An earlier version of the experiment confounded parent selection with
  survivor selection (survivors were drawn only from selected parents +
  offspring, not the full population). This was fixed; all data in this
  summary comes from the corrected implementation (run names ending in
  "_fixed"). Old unfixed runs (parent_fraction_20 / parent_fraction_50,
  without "_fixed") must NOT be used for any comparison.
- Mutation sigma (0.1) and probability (1.0) were not independently tuned
  per condition; they are shared constants carried over unchanged from the
  original Phase-1 config.
- Raw per-generation data (generation, evaluations, best_fitness,
  mean_fitness, std_fitness) is available per run in
  results/parent_fraction_<20|50|80>_fixed_seed_<0-4>/generations.csv
  for deeper analysis (e.g. convergence speed, variance over generations).
- Full config actually used, per run, is saved in
  results/parent_fraction_<20|50|80>_fixed_seed_<0-4>/config.yaml.
